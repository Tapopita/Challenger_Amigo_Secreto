# 🎁 Amigo Secreto

Este proyecto es una aplicación web simple que permite a los usuarios ingresar nombres de amigos y realizar un sorteo aleatorio para elegir un "amigo secreto".

## 🚀 Funcionalidades

- Agregar nombres a una lista.
- Validar que el campo no esté vacío.
- Evitar nombres duplicados.
- Mostrar la lista de amigos ingresados.
- Sortear un amigo secreto de forma aleatoria.
- Limpiar la lista y mostrar solo el resultado del sorteo.

## 🛠️ Tecnologías utilizadas

- HTML5
- CSS
- JavaScript
- Visual Studio Code
